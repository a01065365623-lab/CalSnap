CalSnap 데이터 삭제 안내

앱: CalSnap | 개발자: K-Brain Games Lab | 문의: teeth07@naver.com

CalSnap은 회원가입 없이 임시 사용자 ID(UUID) 기반으로 동작하는 앱이며, 모든 기록은 서버가 아닌 기기 내부 로컬 데이터베이스에만 저장됩니다. 이용자는 별도의 승인 절차 없이 앱 내에서 직접, 그리고 언제든지 본인의 데이터를 삭제할 수 있습니다.

1. 앱 내에서 직접 삭제하는 방법

  1. 특정 날짜의 기록만 삭제: 홈 화면에서 원하는 날짜의 상세 기록 화면으로 들어간 뒤, 상단의 삭제 아이콘(휴지통)을 누르면 그 날짜의 식사·운동·체중·물 섭취 기록이 즉시 삭제됩니다.
  2. 신체 프로필만 초기화: 설정 화면의 프로필 초기화 항목을 선택하면 성별·나이·키·체중·목표 칼로리 등 온보딩 시 입력한 신체 정보가 초기화됩니다. 이미 저장된 일일 기록에는 영향을 주지 않습니다.
  3. 모든 기록을 한 번에 삭제: 설정 화면에서 앱 잠금(시크릿 모드)을 켠 뒤 잠금 화면에서 "비밀번호를 잊으셨나요?"를 선택하고 초기화를 진행하면, 저장된 모든 기록(식사·운동·체중·물 섭취)과 신체 프로필, 잠금 설정(PIN 해시)까지 한 번에 삭제되고 온보딩 화면으로 돌아갑니다. 현재 이 방법이 앱 내에서 전체 데이터를 한 번에 지울 수 있는 유일한 경로입니다.

위 방법 모두 즉시 반영되며, 별도의 승인 절차나 대기 시간이 없습니다.

2. 앱 삭제(제거) 시

앱을 기기에서 삭제(언인스톨)하면 기기에 저장되어 있던 모든 로컬 데이터(기록, 신체 정보, 임시 사용자 ID, PIN 해시)가 함께 제거됩니다. CalSnap은 이 데이터를 별도 서버에 보관하지 않으므로, 언인스톨만으로 데이터 삭제가 완료됩니다.

3. 이메일 문의

CalSnap은 이용자의 기록을 서버에 별도로 저장하지 않으므로, 저희 쪽에서 대신 삭제해 드려야 할 서버 데이터가 없습니다. 다만 위 방법으로 삭제가 어렵거나 문의사항이 있으시면 아래 이메일로 연락해주세요.

4. 삭제되는 데이터 항목

  • 온보딩 시 입력한 신체 정보(성별, 나이, 키, 체중, 목표 칼로리)
  • 식사·운동·체중·물 섭취 기록 전체
  • 앱 잠금(PIN) 해시값
  • 기기 내에 저장된 임시 사용자 ID

CalSnap Data Deletion Instructions

App: CalSnap | Developer: K-Brain Games Lab | Contact: teeth07@naver.com

CalSnap operates without user registration, using a temporary user ID (UUID) per device, and every record is stored only in a local database on your device — never on a server. Users can delete their own data directly within the app at any time, with no approval process required.

1. Deleting Data Directly in the App

  1. Delete records for a single date: open a date's detail screen from the home screen and tap the trash icon at the top to instantly delete that date's meal, exercise, weight, and water logs.
  2. Reset your body profile only: in Settings, select Reset Profile to clear the sex, age, height, weight, and calorie-goal information entered during onboarding. This does not affect your saved daily logs.
  3. Delete everything at once: in Settings, turn on App Lock (Secret Mode), then on the lock screen choose "Forgot your password?" and confirm the reset. This deletes all saved logs (meals, exercise, weight, water), your body profile, and the lock settings (PIN hash) together, and returns you to onboarding. This is currently the only in-app path that wipes all data in one step.

All of the above take effect immediately, with no approval process or waiting period.

2. When Uninstalling the App

Uninstalling the app removes all locally stored data (logs, body information, the temporary user ID, and the PIN hash) from the device. CalSnap does not keep this data on any server, so uninstalling alone completes the deletion.

3. Contact by Email

Because CalSnap does not store your records on a server, there is no server-side data for us to delete on your behalf. If you have trouble deleting data using the steps above, or have any questions, feel free to reach out.

Email: teeth07@naver.com
We'll respond within a reasonable timeframe.

4. Data Covered by Deletion

  • Body information entered during onboarding (sex, age, height, weight, calorie goal)
  • All meal, exercise, weight, and water intake logs
  • App lock (PIN) hash value
  • The temporary user ID stored on your device

Advertising identifiers collected via Google AdMob are managed under Google's own policies and can be managed separately via Google Ad Settings.
